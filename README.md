## 🎚️ What is this?

A custom-built **MIDI DJ console** designed and built from scratch.

The project combines custom hardware, controls, and MIDI communication into a compact DJ controller.

## 🔴⚫ The Console

The console features a simple **black and red** design with:

* 🎚️ Faders
* 🔘 Buttons
* 💡 LED controls
* 🎛️ Rotary controls
* 🎹 MIDI connectivity

The hardware and layout are still a work in progress.
